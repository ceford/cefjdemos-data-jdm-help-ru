## Описание

Эта страница позволяет обновить Joomla! с помощью пакета обновления из
репозитория исходного кода Joomla!. Лучше и безопаснее всего позволить Joomla
обновить себя этим способом.

## Как получить доступ

На **Главной панели управления → Панели уведомлений** значок Joomla будет
содержать одно из двух сообщений:
- **Joomla обновлена**
- **Доступна версия X.Y.Z — обновить сейчас!**

Выберите значок.

Кроме того, в разделе **Система → Панель обновлений → Joomla** будет
отображаться галочка, означающая, что система обновлена, или номер версии,
означающий, что доступна новая версия.

Если обновляется основная или дополнительная версия, вы увидите экран

вмешательство.

## Начать обновление

Если у вас установлена не последняя версия Joomla, вы можете установить
последнее обновление с этой страницы. Для этого убедитесь, что вы создали
резервную копию, и установите флажок **Я осведомлён...**, чтобы подтвердить
это. Затем выберите кнопку **Начать обновление**, и Joomla установит последнюю
версию.

На экране обновления отображается индикатор выполнения, пока идёт обновление.

### Загрузить и обновить

Эту кнопку можно использовать для обновления Joomla, если ваш сервер находится
за межсетевым экраном или по другой причине не может связаться с серверами
обновлений. Сначала скачайте пакет обновления Joomla в формате ZIP с
официальной страницы загрузки Joomla.

Параметры PHP *upload_max_filesize* и *post_max_size* должны быть установлены
на 64 МБ, а ограничение памяти PHP — на 256 МБ. В противном случае обновление
может завершиться ошибкой. Ещё одна веская причина создать резервную копию!

![Загрузка и обновление — загрузка и установка](../../../en/images/joomla-update/joomla-update/04-upload-update-upload-install.png)

## Параметры обновления

Кнопка **Параметры** на панели инструментов позволяет выбрать тип обновления:

- **По умолчанию** Используется для сайтов, настроенных на сохранение
  установленной версии.
- **Joomla Next** Используется для сайтов, которые обычно переходят на
  следующую основную версию сразу после выпуска стабильной версии.
- **Пользовательский URL** Для разработчиков, чтобы выбрать источник обновлений.
