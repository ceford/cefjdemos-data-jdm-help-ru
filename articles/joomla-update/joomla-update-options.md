## Описание

Страница «Обновление Joomla: параметры» используется для настройки параметров, управляющих процессом обновления
ядра Joomla.

### Общие элементы

Некоторые аспекты этой страницы рассматриваются в отдельных справочных статьях:

* [Панели инструментов](jdocmanual?article=help/common-elements/toolbars)

## Как получить доступ

- Выберите **Система → Панель обновлений → Joomla** в меню администратора. Затем...
  - Нажмите кнопку **Параметры** на панели инструментов.

## Поля формы

### Вкладка «Источник обновлений»

- **Канал обновлений**
  - **По умолчанию** Этот параметр позволяет Joomla отображать уведомление о доступности новой минорной версии или версии с исправлениями для текущей мажорной версии.
  - **Следующая версия Joomla** Этот параметр позволяет Joomla отображать уведомление о доступности новой стабильной мажорной версии, если все существующие минорные версии и расширения обновлены до актуальных версий.
  - **Пользовательский URL** Для разработчиков Joomla. Появятся дополнительные поля.
- **Минимальный уровень стабильности** Минимальный уровень стабильности обновлений расширений, которые вы хотите видеть. Версия для разработки является наименее стабильной, стабильная версия соответствует качеству продукта, готового к использованию в рабочей среде. Если для расширения не указан уровень, предполагается, что оно стабильное.
  - **Разработка** Для сайтов разработчиков Joomla.
  - **Альфа** Для сайтов альфа-тестирования.
  - **Бета** Для сайтов бета-тестирования.
  - **Кандидат на выпуск** Для сайтов тестирования кандидатов на выпуск.
  - **Стабильная** Для рабочих сайтов.
- **Пользовательский URL** Если в поле «Канал обновлений» выбран пользовательский URL, здесь появится поле для ввода URL.
- **Флажок потенциально несовместимых расширений** Отображает флажок во время проверки перед обновлением, если какое-либо из установленных на сайте расширений потенциально несовместимо с версией Joomla, до которой выполняется обновление.
  *Примечание:* флажок отображается при обновлении до новой линейки версий Joomla (минорной или мажорной версии).
- **Флажок подтверждения резервного копирования** Отображает флажок для подтверждения того, что резервная копия создана и вы готовы выполнить обновление на последнем шаге перед фактическим применением обновления.

### Вкладка «Автоматические обновления»

*Автоматические обновления доступны начиная с Joomla 5.4 для сайтов, доступных в Интернете. Если ваш сайт находится за межсетевым экраном или недоступен из Интернета, например в локальной тестовой среде, необходимо выполнять обновление вручную.*

![Параметры обновления Joomla: источник обновлений](../../../ru/images/joomla-update/joomla-update-options/02-automated-updates.png)

- **Автоматическое обновление** Если установлено значение *Да*, сайт будет автоматически обновляться до последней минорной версии или версии с исправлениями (включая исправления безопасности), как только она станет доступна. Мажорные версии не включаются.
- **Токен обновления** Это токен, идентифицирующий данный сайт. Он создаётся удалённым сервером обновлений Joomla и не может быть изменён пользователем.
- **Последняя проверка** Самая последняя дата обращения сайта к серверу обновлений.
- **Отправлять электронные письма группам пользователей** Все пользователи из выбранных групп будут получать электронные письма об успешных или неудачных автоматических обновлениях. Если пользователи не найдены, письма отправляются всем суперадминистраторам. У получателей должен быть включён параметр «Получать системные письма».

Для получения дополнительной информации используйте кнопку *Переключить встроенную справку*.
