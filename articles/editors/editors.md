## TinyMCE

TinyMCE — это редактор по умолчанию для пользователей Frontend и Backend. Редактор
предоставляет пользователям привычный интерфейс текстового редактора для редактирования
материалов.

TinyMCE можно настроить с использованием 3 различных наборов кнопок панели инструментов. Это
настраивается в плагине «Редактор — TinyMCE».

### Панели инструментов

#### Простой набор

Набор панели инструментов 2 предоставляет одну строку кнопок, как показано ниже. Этот набор
по умолчанию назначен группе пользователей Public.

![Панель инструментов TinyMCE, набор 2](../../../en/images/editors/editors/01-set-2.png)

- Кнопки позволяют сделать текст полужирным, подчеркнутым или зачеркнутым.
- Отмена и повтор действия.
- Маркированный список, нумерованный список.
- Вставить как текст: часто при копировании и вставке текста из других источников,
  например PDF-файлов, текстовых документов или веб-страниц, выделенный текст
  содержит сведения о форматировании, которые не нужны или нежелательны. При использовании
  функции «Вставить как текст» из текста удаляется все форматирование.

#### Средний набор

Набор панели инструментов 1 предоставляет две строки кнопок, как показано ниже. Этот набор
по умолчанию назначен группам пользователей Manager и Registered.

![Панель инструментов TinyMCE, набор 1](../../../en/images/editors/editors/02-set-1.png)

Этот вариант предоставляет все те же кнопки, которые описаны выше для панели инструментов набора 2.
Кроме того, доступны следующие параметры.

#### Средний набор: верхняя строка

- Материалы CMS: раскрывающийся список предоставляет доступ к ссылкам на
  материал, контакт, поле, медиафайл, меню или модуль.

Материал: пример показывает, как легко создать ссылку на любой материал на
текущем сайте.

![Модальное окно выбора ссылки TinyMCE](../../../en/images/editors/editors/03-link-button.png)

Чтобы создать ссылку на нужный материал:

- Поместите курсор в том месте материала, где должно быть вставлено название
  связанного материала.
- Нажмите кнопку «Материал», чтобы открыть окно.
- Нажмите на заголовок, чтобы выбрать нужный материал в окне. Вы
  можете использовать поиск и фильтры, чтобы найти нужный материал.
- В текущем месте расположения курсора будет вставлена ссылка с названием материала.
- При необходимости можно изменить текст ссылки.

Таким же образом можно создавать ссылки на другие элементы, например медиафайлы, модули и так далее.

Разрыв страницы: эта кнопка позволяет вставить разрыв страницы внутри
материала. Разрыв страницы обеспечивает навигацию по страницам при отображении материала
в макете. Это полезно для длинных материалов. При нажатии этой кнопки
отображается окно, как показано ниже:

![Форма разрыва страницы TinyMCE](../../../en/images/editors/editors/04-pagebreak-button.png)

- **Заголовок страницы**. Введите заголовок, который будет отображаться для новой страницы (например,
  «Страница 2»).
- **Псевдоним оглавления**. Необязательное поле, отображаемое в оглавлении
  этой страницы. В многостраничном материале Joomla отображает
  «оглавление» страницы, позволяющее пользователю выбрать любую
  страницу. Если это поле пусто, будет использован заголовок страницы. Если в оглавлении
  требуется отображать другой заголовок, введите его здесь.
- **Вставить разрыв страницы**. Нажмите эту кнопку, чтобы вставить разрыв страницы с
  введенными данными. Разрыв страницы отображается в виде серой пунктирной линии
  по всей ширине материала. Обратите внимание, что разрыв страницы нельзя редактировать. Если
  необходимо изменить поле разрыва страницы, нажмите в материале сразу
  после разрыва страницы, нажимайте Backspace, пока разрыв страницы не будет удален,
  затем вставьте новый разрыв страницы с нужными данными.
- Настройка выполняется в плагине «Материалы — Разрыв страницы».

Подробнее: эта кнопка вставляет в материал разрыв «Подробнее». Он
отображается в виде красной пунктирной линии по всей ширине материала.

- Если материал содержит разрыв «Подробнее», изначально будет отображаться только текст до разрыва,
  называемый вводным текстом, вместе со ссылкой «Подробнее». Если пользователь нажмет эту ссылку,
  будет отображен либо весь материал, либо только
  часть после ссылки «Подробнее». Это зависит от значения параметров
  вводного
  текста
  материала.
- Разрыв «Подробнее» позволяет экономить место на страницах, отображая только
  вводный текст.
- Если требуется вставить разрывы в материал, отображаемый в макете материала,
  используйте кнопку «Разрыв страницы».

Кнопки в раскрывающемся списке содержимого CMS можно отключить в разделе
«Плагины — editors-xtd».

- Кнопки в левом верхнем углу позволяют сделать текст курсивным. Рядом
  находятся кнопки выравнивания по левому краю, по правому краю, по центру и
  по ширине.
- Форматы: выбор предопределенных форматов для заголовков, встроенных элементов, блоков и
  так далее.
- Уменьшить отступ (сдвинуть влево) и увеличить отступ (сдвинуть вправо).
- Три точки: показать вторую строку панели инструментов.

#### Средний: второй ряд

- Вставить/редактировать ссылку: чтобы вставить или отредактировать ссылку, выберите связанный текст и нажмите эту кнопку. Откроется всплывающее диалоговое окно, в котором можно ввести сведения о ссылке.
- Удалить ссылку: чтобы удалить ссылку, выделите связанный текст и нажмите эту кнопку.
- Якорь: якорь — это закладка внутри статьи, позволяющая создать ссылку непосредственно на определённое место в статье.
- Исходный код: откроется всплывающее окно с исходным кодом HTML, в котором можно редактировать исходный код HTML.
- Вставить горизонтальную линию: чтобы вставить горизонтальную линию, переместите курсор в нужное место статьи и нажмите эту кнопку.
- Таблица: вставить новую таблицу, свойства строки таблицы, свойства ячейки таблицы, вставить строку перед, вставить строку после, удалить строку, вставить столбец перед, вставить столбец после, удалить столбец, разделить объединённые ячейки таблицы, объединить ячейки таблицы.
- Нижний индекс, верхний индекс, специальный символ.
- Предварительный просмотр текста во всплывающем окне.

#### Расширенный набор

Набор панели инструментов 0 предоставляет наиболее широкий набор возможностей редактирования, как показано ниже. По умолчанию этот набор назначен группам пользователей «Администраторы», «Редакторы» и «Суперпользователи».

![Набор данных TinyMCE 0](../../../en/images/editors/editors/05-set-0.png)

Этот вариант предоставляет все те же кнопки, что описаны выше в панели инструментов набора 1. Кроме того, доступны следующие параметры.

#### Расширенный: верхний ряд

- Блоки: абзац, заголовки, предварительно отформатированный текст.
- Шрифты: выбор нужного шрифта.
- Размер шрифта: выбор нужного размера шрифта.
- Поиск и замена.
- Вставить/редактировать изображение: чтобы вставить изображение, установите курсор в нужное место и нажмите эту кнопку. Откроется всплывающее диалоговое окно, в котором можно указать источник, ширину или высоту и другие сведения об изображении.

#### Расширенный: второй ряд

- Выбрать цвет текста или цвет фона.
- Полноэкранный режим.
- Смайлы.
- Вставить мультимедиа: чтобы вставить мультимедийный объект, установите курсор в нужное место и нажмите эту кнопку. Откроется всплывающее диалоговое окно, в котором можно указать тип, файл или URL и другие сведения о мультимедийном объекте.
- Направление слева направо или направление справа налево: эти кнопки позволяют задать или изменить направление текста, например для языков, которые читаются справа налево.
- Вырезать, копировать, вставить.
- Показывать невидимые символы (например, окончания абзацев).
- Показывать блоки.
- Неразрывный пробел.
- Цитата.
- Вставить шаблон.

#### Расширенный: третий ряд

- Распечатать текст статьи.
- Вставить/редактировать образец кода.
- Вставить дату/время.
- Очистить форматирование.

## CodeMirror

«Редактор — CodeMirror» предназначен для упрощения ввода HTML-кода
в статье или описании. CodeMirror поддерживает подсветку синтаксиса
и автодополнение, как показано на этом снимке экрана.

![Форма редактирования CodeMirror](../../../en/images/editors/editors/06-codemirror.png)

- Кнопки, показанные под окном редактирования, предоставляют доступ к ссылкам на любые элементы сайта.
- CodeMirror предлагает некоторые из тех же преимуществ, что и «Редактор — None», но несколько упрощает работу с необработанным HTML-кодом.
- Конфигурация задаётся в плагине «Редактор —
  CodeMirror
  ».

## Нет

Если для пользователя выбран параметр «Редактор — Нет», отображается простой текстовый редактор. Это позволяет вводить необработанный неформатированный HTML-код. С помощью кнопки панели инструментов «Предпросмотр» можно посмотреть, как будет отображаться HTML-код.

Обратите внимание, что параметр «Нет» может быть полезен при вводе «шаблонного» или пользовательского HTML-кода, например для создания ссылки PayPal. TinyMCE автоматически переформатирует и удаляет некоторые элементы HTML при сохранении файла. Это может привести к некорректной работе сложного HTML-кода.

Если это происходит, можно временно изменить редактор на «Нет» и создать необходимое содержимое. Обратите внимание: если в будущем потребуется изменить это содержимое, следует не забыть установить для редактора значение «Нет». В противном случае при открытии и сохранении содержимого с помощью TinyMCE можно потерять пользовательский HTML-код.

Плагин «Редактор — Нет» не имеет настроек.
